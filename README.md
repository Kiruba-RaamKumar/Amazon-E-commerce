# Amazon-E-commerce

 Project Overview

This project presents an interactive Amazon Sales Performance Dashboard developed using Power BI. It provides a comprehensive overview of sales performance, customer insights, product categories, and delivery status to support data-driven business decisions.

 Key Performance Indicators (KPIs)

- Total Sales: 9.94 Billion
- Total Orders: 1 Million
- Unique Customers: 604K
- Average Selling Price: 9.94K
- Average Product Rating: 3.93
- Return Rate: 0.12%

 Dashboard Features

- Monthly Sales Analysis
- Sales by Product Category
- Sales by Subcategory
- Top 5 Products by Sales
- Sales by Delivery Status
- Monthly Profit and Sales Analysis
- Interactive Filters:
  - Year
  - Brand
  - Location
  - Payment Method

Tools & Technologies

- Power BI
- Data Visualization
- Data Analysis
- Business Intelligence

 Project Objectives

- Analyze overall Amazon sales performance.
- Identify top-performing products and categories.
- Understand monthly sales trends.
- Evaluate delivery and return performance.
- Generate meaningful business insights.

 Key Learnings

Gained practical experience in KPI development, interactive dashboard creation, data visualization, and business performance analysis.

 Project Type
